# User Flow PhotoHome

PhotoHome описывает интерфейс через пользовательские задачи и сущности, а не через отдельные экраны. При добавлении новой функции сначала обновляется этот User Flow и каноническое меню соответствующей сущности, затем начинается разработка.

## Главная

- Просмотреть полки.
- Создать новый альбом.
- Импортировать фотографии.
- Создать глобальную метку.
- Перейти в карантин.
- Перейти к поиску.
- Запустить фотокиоск.

## Полка

- Просмотреть альбомы.
- Создать альбом.
- Импортировать фотографии.
- Просмотреть «Неразобранное».
- Управлять альбомом.
- Запустить фотокиоск полки.

Импорт с полки не добавляет фотографии прямо на полку. Пользователь выбирает существующий альбом, создаёт новый альбом или отправляет фотографии в «Неразобранное» этой полки.

## Альбом

- Просмотреть фотографии.
- Добавить фотографии.
- Управлять альбомом.
- Создать раздел.
- Управлять разделами.
- Управлять фотографиями.
- Запустить фотокиоск альбома.

## Фото

- Просмотреть фотографию.
- Переключиться между фотографиями.
- Управлять фотографией.
- Добавить метки.
- Добавить в раздел.

## Карантин

- Просмотреть объекты.
- Восстановить.
- Удалить окончательно.

## Контекст сущностей

### Альбом

Контекст:

- карточка;
- открыт;
- результаты поиска;
- избранное;
- история.

Меню: Album Menu.

### Фото

Контекст:

- сетка;
- полноэкранный просмотр;
- результаты поиска;
- раздел;
- метка.

Меню: Photo Menu.

## Правило развития

UX первичен, код вторичен: новая возможность сначала фиксируется в User Flow и каноническом меню, затем реализуется в интерфейсе и бизнес-логике.
