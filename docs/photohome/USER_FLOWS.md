# User Flow PhotoHome

Документ фиксирует пользовательские задачи для первой версии PhotoHome. Он описывает ожидаемое поведение, а не текущий статус реализации.

## Главная страница

- Просмотреть полки.
- Перейти к выбранной полке.
- Создать альбом: выбрать полку, указать название.
- Импортировать фотографии: выбрать существующий альбом, создать новый альбом или выбрать «Неразобранное» нужной полки.
- Создать глобальную метку.
- Перейти к карантину, поиску или фотокиоску.

## Полка

- Просмотреть альбомы и «Неразобранное».
- Создать альбом на текущей полке.
- Импортировать фотографии в контексте полки:
  1. выбрать существующий альбом этой полки;
  2. создать на полке новый альбом;
  3. поместить фотографии в «Неразобранное» этой полки.
- Управлять альбомом из карточки, не переходя внутрь.
- Открыть «Неразобранное» и разобрать его содержимое.
- Запустить фотокиоск для полки.

Фотографии не добавляются непосредственно на полку: полка содержит только альбомы и свой раздел «Неразобранное».

## Альбом

- Просмотреть фотографии и разделы.
- Добавить фотографии в текущий альбом.
- Управлять текущим альбомом.
- Создать раздел, переименовать его, изменить порядок или удалить раздел.
- Управлять отдельной фотографией из сетки.
- Выбрать одну или несколько фотографий и выполнить общее действие.
- Запустить фотокиоск альбома.

## Фотография

- Открыть фотографию кликом из сетки, раздела, метки или результатов поиска.
- Переключаться между фотографиями.
- Добавить метки; при необходимости создать локальную или глобальную метку.
- Добавить в раздел.
- Сделать обложкой альбома.
- Просмотреть информацию и отправить в карантин.

## Карантин

- Просмотреть альбомы и фотографии в карантине.
- Восстановить объект в исходное расположение.
- При конфликте имени переименовать восстанавливаемый объект, выбрать другое место или отменить действие.
- Окончательно удалить один или несколько объектов.

## Общие правила сценариев

- Одно действие использует один сценарий, диалог, проверку и результат независимо от точки входа.
- Точка входа передаёт только известный контекст: например, при импорте из альбома цель уже определена, а при глобальном импорте её нужно выбрать.
- Открытие объекта — навигация по клику, а не пункт контекстного меню.
- Новый сценарий сначала фиксируется в этом документе и в спецификации меню, затем реализуется.
