# Канонические меню PhotoHome

Меню принадлежит сущности, а не странице. Один и тот же набор действий используется в любой точке, где пользователь взаимодействует с этой сущностью: через кнопку `⋮`, контекстное меню, клавиатуру или долгий тап.

## Общие правила

- Не добавлять пункт «Открыть»: объект открывается кликом по карточке или элементу.
- Одно действие запускает один сценарий независимо от точки входа.
- Контекст точки входа только заполняет уже известные данные.
- Порядок пунктов стабилен во всех точках касания.
- Деструктивные действия отделяются разделителем и располагаются внизу.
- Действия, не относящиеся к текущему состоянию сущности, скрываются.
- Временно невозможные действия остаются видимыми и объясняют причину.
- Будущие функции показываются как запланированные и не имитируют доступную функцию.

## Меню полки

Используется на странице полки.

```text
Создать альбом
Импортировать фотографии
Просмотреть «Неразобранное»

────────────────
Запустить фотокиоск
```

## Меню альбома

Используется:

- карточка альбома;
- открытый альбом;
- результаты поиска;
- избранное;
- история.

```text
Добавить фотографии
Переименовать
Изменить обложку                   [запланировано]
Изменить описание                  [запланировано]
Изменить дату                      [запланировано]
Переместить на другую полку        [запланировано]
Объединить с альбомом              [запланировано]
Экспортировать альбом              [запланировано]
Поделиться                         [запланировано]

────────────────
Запустить фотокиоск                [запланировано]

────────────────
Отправить в карантин               [запланировано]
```

Если альбом пустой, «Изменить обложку» остаётся в меню, но недоступно с пояснением.

## Меню фотографии

Используется:

- карточка фотографии;
- открытая фотография;
- результаты поиска;
- раздел;
- метка.

```text
Добавить метки                     [запланировано]
Добавить в раздел                  [запланировано]
Сделать обложкой альбома           [запланировано]
Изменить дату и время              [запланировано]
Переместить в другой альбом        [запланировано]
Повернуть                          [запланировано]
Скачать оригинал                   [запланировано]

────────────────
Показать информацию

────────────────
Отправить в карантин
```

## Меню раздела

```text
Добавить выбранные фотографии      [запланировано]
Переименовать                      [запланировано]
Изменить порядок                   [запланировано]

────────────────
Удалить раздел                     [запланировано]
```

Удаление раздела не удаляет фотографии; это должно быть явно сказано в подтверждении.

## Меню выбранных фотографий

```text
Добавить метки                     [запланировано]
Добавить в раздел                  [запланировано]
Переместить                        [запланировано]
Экспортировать                     [запланировано]

────────────────
Отправить в карантин
```

## Меню карантина

Используется для карточки объекта и просмотра объекта в карантине.

```text
Восстановить
Показать исходное расположение

────────────────
Удалить окончательно
```

В карантине не показываются обычные действия активной библиотеки: добавление фотографий, переименование, изменение обложки и запуск фотокиоска.

## Карта точек касания

### Главная

Доступны:

- глобальное меню;
- меню полки.

### Полка

Доступны:

- глобальное меню;
- меню полки;
- меню альбома.

### Альбом

Доступны:

- глобальное меню;
- меню альбома;
- меню фотографии;
- меню раздела, если открыта группировка;
- меню выбранных фотографий.

### Открытая фотография

Доступны:

- глобальное меню;
- меню фотографии.

Полное меню альбома в просмотрщике фотографии отдельно обсуждается перед реализацией.

### Карантин

Доступны:

- меню объекта в карантине;
- меню выбранных объектов.
