# Канонические меню PhotoHome

Меню принадлежит сущности, а не странице. Один и тот же набор действий используется в любой точке, где пользователь взаимодействует с этой сущностью: через кнопку `⋮`, контекстное меню, клавиатуру или долгий тап.

## Общие правила

- Пункт «Открыть» не используется: объект открывается кликом.
- Одно действие запускает один сценарий независимо от точки входа; контекст только заполняет известные данные.
- Порядок пунктов стабилен во всех точках касания.
- Будущие функции уже включаются в меню, чтобы зафиксировать UX-паттерн. Их статус реализации показывается отдельно: «готово», «в разработке» или «запланировано».
- Действия, не относящиеся к текущему жизненному состоянию сущности, скрываются. Временно невозможные действия остаются видимыми и объясняют причину.
- Деструктивные действия отделяются разделителем и располагаются внизу.
- Во время выполнения повторный запуск действия недоступен; ошибка сообщается отдельно и не меняет постоянный состав меню.

## Точки касания

| Точка | Доступные меню |
| --- | --- |
| Главная | глобальные действия, меню полки |
| Полка | меню полки, меню карточки альбома |
| Альбом | меню альбома, меню фотографии, меню раздела, меню выбранных фотографий |
| Открытая фотография | меню фотографии; альбом доступен через навигационную цепочку |
| Поиск, метка, раздел | меню найденной или отображаемой сущности |
| Карантин | меню объекта в карантине и меню выбранных объектов |

## Меню полки

```text
Создать альбом
Импортировать фотографии
Просмотреть «Неразобранное»

────────────────
Запустить фотокиоск
```

«Импортировать фотографии» всегда предлагает только допустимые цели на текущей полке: существующий альбом, новый альбом или «Неразобранное». Непосредственного добавления фотографий на полку нет.

## Меню альбома

Используется для карточки альбома, открытого альбома, результатов поиска и других представлений активного альбома.

```text
Добавить фотографии
Переименовать
Изменить обложку
Изменить описание
Изменить дату
Переместить на другую полку
Объединить с альбомом
Экспортировать альбом
Поделиться

────────────────
Запустить фотокиоск

────────────────
Отправить в карантин
```

Для пустого альбома «Изменить обложку» временно недоступно с пояснением. В карантине это меню заменяется меню состояния карантина.

## Меню фотографии

Используется для карточки в сетке, открытой фотографии, результатов поиска, раздела и метки.

```text
Добавить метки
Добавить в раздел
Сделать обложкой альбома
Изменить дату и время
Переместить в другой альбом
Повернуть
Скачать оригинал

────────────────
Показать информацию

────────────────
Отправить в карантин
```

## Меню раздела

```text
Добавить выбранные фотографии
Переименовать
Изменить порядок

────────────────
Удалить раздел
```

Удаление раздела не удаляет фотографии: они остаются в альбоме. Это явно сообщается в подтверждении.

## Меню метки

```text
Переименовать
Изменить область действия

────────────────
Удалить метку
```

Локальная метка относится к текущему альбому, глобальная — ко всей библиотеке. Диалог добавления метки показывает обе группы и может предложить создать новую метку с выбором области действия.

## Меню выбора фотографий

Применяется к одной или нескольким выбранным фотографиям и содержит только действия, поддерживающие выборку.

```text
Добавить метки
Добавить в раздел
Переместить
Экспортировать

────────────────
Отправить в карантин
```

Действия, требующие ровно одну фотографию, например «Сделать обложкой альбома», в этом меню появляются только при выборе одного объекта.

## Меню объекта в карантине

Для альбома и фотографии в карантине используется состав, соответствующий их состоянию:

```text
Восстановить
Показать исходное расположение

────────────────
Удалить окончательно
```

Активные действия, такие как импорт в альбом, переименование или изменение обложки, в карантине скрываются. Восстановление по умолчанию возвращает объект на исходное место; при конфликте пользователь выбирает переименование, другое место или отмену.
